# 스케줄 — 학교 일정 대시보드

**영동고등학교**(경북 영천시 안야사길 13) 기준으로 맞춰진, 급식 · 시간표 · 수행평가 · 정기시험 ·
**익명 건의사항**을 한 화면에서 보는 웹앱입니다.
빌드 도구가 필요 없는 정적 사이트라 GitHub Pages에 그대로 올릴 수 있고, 개인 데이터는 브라우저에만 저장됩니다.

## 화면

| 화면 | 내용 |
| --- | --- |
| **오늘** | 오늘 수업 수·D-day 요약, 오늘 시간표(현재 교시 강조), 오늘 급식(조·중·석식), 다가오는 일정, 이번 주 인기 건의 |
| **급식** | 주간/월간 급식표, 칼로리, 알레르기 번호 (나이스 연동) |
| **시간표** | 5일 × 최대 12교시. 셀을 눌러 직접 입력하거나 나이스에서 가져오기, 교시별 종 시간 설정 |
| **평가** | 수행평가(과목·마감일·완료 체크) ↔ 정기시험(시험 기간·과목·교시·범위) 전환 |
| **건의** | 익명 건의 등록, 좋아요, **이번 주 좋아요 1위** 자동 노출, 최신순/인기순/내 건의 필터 |
| **설정** | 학교 검색, 학년/반, 나이스 인증키, 공유 게시판 연결, 테마, 백업·복원 |

## 모바일

아이폰·갤럭시 전 기종을 기준으로 만든 **모바일 퍼스트** 레이아웃입니다.

- 하단 탭바 + 화면별 색상 테마, 상단 앱바는 스크롤에 반응
- 노치·홈 인디케이터(safe-area) 대응, iOS 100dvh 대응, 탭 하이라이트 제거
- 모든 터치 영역 44px 이상, 입력창 글자 16px(포커스 시 화면 확대 방지)
- 모달은 모바일에서 **바텀시트**(손잡이를 아래로 끌어 닫기), 데스크톱에서는 가운데 정렬
- 갤럭시 폴드 접힘(344px)부터 아이폰 프로 맥스(430px), 태블릿, 데스크톱까지 가로 넘침 없음
- 홈 화면에 추가하면 전체화면 앱처럼 실행 (웹 매니페스트 + 아이콘 포함)

## 시작하기

ES 모듈이라 `file://` 로는 동작하지 않습니다. 로컬에서는 정적 서버로 여세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages 배포는 **Settings → Pages** 에서 Source 를 `Deploy from a branch`,
브랜치를 이 브랜치의 루트(`/`)로 지정하면 됩니다.

학교는 영동고등학교로 기본 설정돼 있고, 설정 화면에서 언제든 다른 학교로 바꿀 수 있습니다.

## 건의사항 — 두 가지 모드

| 모드 | 설명 |
| --- | --- |
| **이 기기 전용** (기본) | 건의·좋아요가 내 브라우저에만 저장됩니다. 설치 없이 바로 사용 |
| **공유 모드** | 반 전체가 같은 건의 목록과 좋아요를 봅니다. 무료 Google Apps Script 백엔드 사용 |

공유 모드 켜는 법:

1. [script.google.com](https://script.google.com) 에서 새 프로젝트 생성 → `backend/apps-script.gs` 내용 붙여넣기
2. **배포 → 새 배포 → 웹 앱**, 실행 계정 `나`, 액세스 권한 `모든 사용자`
3. 나온 웹앱 주소(`.../exec`)를 사이트 **설정 → 건의사항 공유 게시판** 에 붙여넣기

어느 모드든 글쓴이 이름·계정은 저장하지 않습니다. 좋아요 중복 방지를 위한 익명 기기 식별자만 사용하며,
서버 쪽에서는 그마저도 해시해서 보관합니다. 도배 방지로 같은 기기에서 1분에 3건까지만 등록됩니다.

## 나이스 인증키 (선택)

급식·시간표·학사일정은 [나이스 교육정보 개방 포털](https://open.neis.go.kr) OpenAPI에서 가져옵니다.

- 인증키 **없이도** 동작하지만 한 번의 조회에서 **최대 5건**만 내려옵니다(주간 급식 일부만 표시됨).
- 포털에서 무료 발급받은 키를 **설정 → 나이스 인증키** 에 넣으면 제한이 풀립니다.
- 키는 서버로 전송되지 않고 이 브라우저에만 저장됩니다.

영동고는 나이스에 시간표를 등록해 두지 않아 시간표 가져오기 결과가 비어 있을 수 있습니다. 이 경우 직접 입력하면 됩니다.

## 데이터

- 학교·시간표·수행평가·시험·건의(로컬 모드)는 localStorage 에 저장됩니다.
- 나이스 조회 결과는 sessionStorage 에 캐시되며 설정에서 비울 수 있습니다.
- **설정 → 데이터** 에서 JSON 백업을 내보내고 다시 가져올 수 있습니다.

## 구조

```
index.html                 앱 셸 (사이드바 / 탭바 / 바텀시트 모달)
manifest.webmanifest       홈 화면 추가용 매니페스트
assets/css/style.css       디자인 토큰, 라이트·다크, 화면별 색상, 반응형
assets/icon*.png|svg       앱 아이콘
assets/js/
  app.js                   해시 라우팅, 탭바/사이드바, 테마, FAB
  store.js                 상태 + localStorage, 파생 데이터
  neis.js                  나이스 OpenAPI (급식/시간표/학사일정/학교검색)
  board.js                 건의사항 저장소 (로컬 / 공유 모드)
  data.js                  나이스 조회 캐시
  ui.js                    모달·카드·빈 상태 등 공용 UI
  utils.js                 날짜·DOM·아이콘 유틸
  views/                   today · meal · timetable · assessments · exams · suggestions · settings
backend/apps-script.gs     건의 공유 게시판 백엔드 (Google Apps Script)
```

의존성 없음. 순수 HTML/CSS/ES 모듈이며 웹폰트(Pretendard)만 CDN에서 불러옵니다.
