# 스케줄 — 학교 일정 대시보드

**영동고등학교**(경북 영천시 안야사길 13) 기준으로 맞춰진, 급식 · 시간표 · 수행평가 · 정기시험 ·
**익명 건의사항**을 한 화면에서 보는 웹앱입니다.
빌드 도구가 필요 없는 정적 사이트라 GitHub Pages에 그대로 올릴 수 있고,
공용 데이터는 무료 Google Apps Script 서버 하나로 반 전체가 공유합니다.

**관리자가 올린 시간표·시험·수행평가·노트를 모든 학생이 똑같이 봅니다.** 학생 기기에서는 수정·삭제가 불가능하고,
건의사항만 익명으로 쓰고 좋아요를 누를 수 있습니다.

## 화면

| 화면 | 내용 |
| --- | --- |
| **오늘** | 오늘 수업 수·D-day 요약, 오늘 시간표(현재 교시 강조), 오늘 급식(조·중·석식), 다가오는 일정, 이번 주 인기 건의 |
| **급식** | 주간은 요일 칩, 월간은 달력에서 날짜를 골라 그 날 것만 — 조식·중식·석식 탭, 메뉴는 칩으로 (나이스 연동) |
| **시간표** | 5일 × 최대 12교시. 셀을 눌러 직접 입력하거나 나이스에서 가져오기, 교시별 종 시간 설정 |
| **평가** | 수행평가(과목·마감일·완료) ↔ 정기시험(기간·과목·교시·범위) 전환 |
| **노트** | 과목별 요점정리 — 필기 사진·PDF 첨부, 과목 탭으로 모아 보기 (등록은 관리자, 열람은 모두) |
| **건의** | 익명 건의 등록, 좋아요, **이번 주 좋아요 1위** 자동 노출, 최신순/인기순 |
| **관리자 패널** | 학교·학년/반, 나이스 인증키, 공유 게시판 연결, 테마, 백업·복원 (숨김 주소로만 진입) |

## 관리자 패널

설정 화면은 학생들 화면(탭바·사이드바)에 노출되지 않습니다. 12자리 숨김 주소로만 들어갑니다.

```
https://<사이트주소>/#/<12자리 코드>
```

코드는 `assets/js/store.js` 의 `ADMIN_CODE` 상수에 있습니다. 한 번 들어가면 그 기기는 관리자로 기억되어
앱바에 톱니 아이콘이 생기고, 패널 안의 **관리자 끄기** 로 해제할 수 있습니다.

주의: 저장소가 공개라 코드를 열어보면 이 숫자를 찾을 수 있습니다. **비밀번호가 아니라 '숨김'** 입니다.
바꾸고 싶으면 `ADMIN_CODE` 값만 다른 12자리로 교체하세요. 테마 전환은 관리자가 아니어도 앱바에서 됩니다.

## 모바일

아이폰·갤럭시 전 기종을 기준으로 만든 **모바일 퍼스트** 레이아웃입니다.

- 하단 탭바 + 화면별 색상 테마, 상단 앱바는 스크롤에 반응
- 노치·홈 인디케이터(safe-area) 대응, iOS 100dvh 대응, 탭 하이라이트 제거
- 모든 터치 영역 44px 이상, 입력창 글자 16px(포커스 시 화면 확대 방지)
- 모달은 모바일에서 **바텀시트**(손잡이를 아래로 끌어 닫기), 데스크톱에서는 가운데 정렬
- 갤럭시 폴드 접힘(344px)부터 아이폰 프로 맥스(430px), 태블릿, 데스크톱까지 가로 넘침 없음
- 홈 화면에 추가하면 전체화면 앱처럼 실행 (웹 매니페스트 + 아이콘 포함)

## 시작하기

ES 모듈이라 `file://` 로는 동작하지 않습니다. 로컬에서는 정적 서버로 여세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages 배포는 **Settings → Pages** 에서 Source 를 `Deploy from a branch`,
브랜치를 이 브랜치의 루트(`/`)로 지정하면 됩니다.

학교는 영동고등학교로 기본 설정돼 있고, 설정 화면에서 언제든 다른 학교로 바꿀 수 있습니다.

## 공용 서버 — 모두에게 똑같이 보이게

정적 사이트만으로는 기기마다 데이터가 따로 놉니다. 반 전체가 같은 시간표를 보려면 공용 서버가 필요하고,
이 프로젝트는 무료인 **Google Apps Script + 스프레드시트 + 드라이브** 를 씁니다.

| 항목 | 저장 위치 | 누가 수정 |
| --- | --- | --- |
| 시간표 · 정기시험 · 수행평가 | 공용 서버 (스프레드시트) | 관리자만 |
| 요점정리 노트 · 첨부파일 | 공용 서버 + 드라이브 | 관리자만 |
| 건의사항 | 공용 서버 | 등록·좋아요는 누구나, 삭제는 관리자만 |
| 학교·학년/반·나이스 키·테마 | 각자 브라우저 | 각자 |

### 연결 방법

1. [script.google.com](https://script.google.com) 새 프로젝트 → `backend/apps-script.gs` 내용 붙여넣기
2. **배포 → 새 배포 → 웹 앱** · 실행 계정 `나` · 액세스 권한 `모든 사용자`
3. 웹앱 주소(`.../exec`)를 관리자 패널 **공용 서버** 칸에 붙여넣기
4. 같은 화면에서 **관리자 키**(6자 이상)를 정하면 서버에 등록됩니다. 이 키가 있어야 수정이 가능하고,
   학생 기기에는 넣지 않습니다.
5. 시간표·시험을 입력한 뒤 **서버로 올리기** 를 누르면 모든 학생 화면에 같은 내용이 나타납니다.

학생 앱은 실행할 때, 화면으로 돌아올 때, 그리고 5분마다 서버에서 최신 내용을 받아옵니다.

글쓴이 이름·계정은 어디에도 저장하지 않습니다. 좋아요 중복 방지를 위한 익명 기기 식별자만 쓰고,
서버에서는 그마저 해시로 보관합니다. 도배 방지로 같은 기기에서 1분에 3건까지만 등록됩니다.
노트 첨부는 사진 자동 축소 후 최대 8MB까지 올라갑니다.

서버 주소를 넣지 않으면 '이 기기 전용 모드'로, 관리자 혼자 자기 폰에서만 쓰는 상태가 됩니다.

## 나이스 인증키 (선택)

급식·시간표·학사일정은 [나이스 교육정보 개방 포털](https://open.neis.go.kr) OpenAPI에서 가져옵니다.

- 인증키 **없이도** 동작하지만 한 번의 조회에서 **최대 5건**만 내려옵니다(주간 급식 일부만 표시됨).
- 포털에서 무료 발급받은 키를 **설정 → 나이스 인증키** 에 넣으면 제한이 풀립니다.
- 키는 서버로 전송되지 않고 이 브라우저에만 저장됩니다.

시간표 가져오기는 학년·반을 나이스 학급 정보에서 골라 받아옵니다. 이번 주에 수업이 없으면(방학·학기 시작 전)
앞뒤 8주를 훑어 **이번 학기에 등록된 가장 가까운 주** 를 찾아 채웁니다. 개학 전이라면 지난 주가 아니라
다가오는 주를 가져옵니다.

이번 학기 시간표가 나이스에 아직 올라오지 않았다면 지난 학기 것을 말없이 덮어쓰지 않고,
어느 학기 · 몇 월 주 시간표인지 알린 뒤 확인을 받습니다. 영동고는 2학기 시간표 등록이 늦는 편이라
개학 직후에는 이 확인 창이 뜰 수 있고, 등록된 뒤 다시 가져오면 2학기 시간표로 바뀝니다.
학기 구분은 나이스 응답의 학년도·학기(`AY`/`SEM`) 값으로 판단하며, 값이 없으면 날짜로 추정합니다
(2학기 시작은 8월 16일 기준).

## 데이터

- 공유 모드에서는 시간표·시험·수행평가·노트·건의가 공용 서버에 저장되고, 각 기기에는 사본만 캐시됩니다.
- 학교·학년/반·나이스 키·테마는 각 브라우저에만 저장됩니다.
- 나이스 조회 결과는 sessionStorage 에 캐시되며 설정에서 비울 수 있습니다.
- **설정 → 데이터** 에서 JSON 백업을 내보내고 다시 가져올 수 있습니다.

## 구조

```
index.html                 앱 셸 (사이드바 / 탭바 / 바텀시트 모달)
manifest.webmanifest       홈 화면 추가용 매니페스트
assets/css/style.css       디자인 토큰, 라이트·다크, 화면별 색상, 반응형
assets/icon*.png|svg       앱 아이콘
assets/js/
  app.js                   해시 라우팅, 탭바/사이드바, 테마, FAB
  store.js                 상태 + localStorage, 파생 데이터
  neis.js                  나이스 OpenAPI (급식/시간표/학사일정/학교검색)
  server.js                공용 서버 통신 (시간표·시험·평가·노트·건의)
  data.js                  나이스 조회 캐시
  ui.js                    모달·카드·빈 상태 등 공용 UI
  utils.js                 날짜·DOM·아이콘 유틸
  views/                   today · meal · timetable · assessments · exams · notes · suggestions · settings
backend/apps-script.gs     공용 데이터 서버 (Google Apps Script + 스프레드시트 + 드라이브)
```

의존성 없음. 순수 HTML/CSS/ES 모듈이며 웹폰트(Pretendard)만 CDN에서 불러옵니다.
